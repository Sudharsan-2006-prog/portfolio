# Sudharsan Baskar | Developer Portfolio 🚀

A responsive, interactive personal portfolio website designed to showcase my skills, projects, achievements, and journey as a Computer Science student at SSN College of Engineering. 

Built completely from scratch using pure HTML, CSS, and Vanilla JavaScript without any external CSS/JS frameworks.

## ✨ Features

- **Interactive Canvas Background:** A custom-built particle network animation that reacts to mouse movement.
- **Light & Dark Mode:** Seamless theme switching with a modern UI design and CSS variables.
- **Dynamic Typewriter Effect:** An animated text sequence introducing my roles and interests.
- **Staggered Scroll Animations:** Elements smoothly reveal themselves as you scroll down the page using the Intersection Observer API.
- **3D Tilt Cards:** A smooth, interactive 3D hover effect on desktop cards for better user engagement.
- **Animated Statistics:** Number counters that dynamically tally up when scrolled into view.
- **Fully Responsive:** Custom mobile navigation menu and fluid layout ensuring a great experience on all devices.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Custom styling, variables, flexbox/grid layouts, and keyframe animations.
- **Vanilla JavaScript (ES6+):** DOM manipulation, canvas rendering, and scroll event handling.
- **FontAwesome:** For scalable vector icons.
- **Google Fonts:** Utilizing 'Inter' and 'Poppins' for clean typography.
